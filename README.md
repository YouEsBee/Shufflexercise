# Shufflexercise

## Description
An Android app that randomises the exercise plan for the day for seniors.

The app must have large touch targets and large font size for good accessibility as the target users are more likely to have long-sightedness.

## Tech Stack
- Min target SDK 24 (Android 7.0 Nougat)
- Kotlin 2.2.10
- Libraries:
  - Room (TBC)

## Setup
- Clone the project in Android Studio
- Click the triangle run button to run the app in simulator
